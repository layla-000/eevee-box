# Eevee Box

9월까지 가볍게 사용할 개인용 포켓몬 데이터베이스입니다.

## 바로 시험하기

`index.html`을 정적 웹서버나 GitHub Pages에서 열면 됩니다. 백엔드를 연결하기 전에는 브라우저 로컬 저장소에 저장됩니다.

## 데스크톱·모바일 동기화 연결

1. Google Sheets에서 빈 스프레드시트를 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고 `Code.gs` 내용을 붙여넣습니다.
3. **배포 → 새 배포 → 웹 앱**을 선택합니다.
4. 실행 사용자는 본인, 액세스 권한은 링크를 가진 사용자로 설정합니다.
5. 배포 URL을 복사해 `config.js`의 `apiEndpoint`에 넣습니다.
6. 이 폴더 전체를 GitHub Pages에 배포합니다.

첫 접속 시 `pokemon-data.json`의 초기 데이터가 Google Sheets로 자동 입력됩니다.

## 들어 있는 기능

- 포켓몬 카드 목록과 검색·타입 필터
- 카드에서 레벨 ±1 즉시 변경
- 별명, 종류, 타입, 특성, 테라 타입, 성격, 도구, 메모 수정
- 현재 기술 4개 선택
- 원본 데이터에서 추출한 습득 가능 기술 검색
- Google Sheets 기반 기기 간 동기화
- API를 연결하지 않아도 로컬 모드 사용 가능

## 초기 데이터 참고

원본 텍스트에서 22마리와 기술표를 추출했고, 이미지에만 있던 트리미앙은 최소 정보로 추가했습니다. 레벨은 제공된 보유 포켓몬 화면을 기준으로 넣었습니다. 상세 데이터가 없는 항목은 사이트에서 직접 수정할 수 있습니다.
